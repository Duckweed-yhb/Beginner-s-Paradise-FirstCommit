# Beginner's Paradise‑FirstCommit 黑客松完整解读
> 这是面向**13‑21岁学生**的线上新手向Hackathon，完全开放主题，重在学习成长，不要求完美成品。
- 截止时间：**2026‑10‑01 05:00（还有23天）**
- 参赛资格：**仅限13‑21岁学生；企业/专业机构不能参加；全球国家均可**
- 参赛形式：单人 / 组队都可以
- 总奖金池：**952美元+配套会员、域名奖品**
- 标签：Beginner Friendly 新手友好，Web / 移动端 / 硬件 / AI工具都允许做

## 📦提交作品【强制必填项，少一样直接无法参与评审】
1. **可运行的项目**：项目必须是本次黑客松期间开发；允许使用现成库、框架、模板，但**核心业务逻辑必须是比赛期间做出来的**。
2. **公开GitHub仓库源代码**。
3. **项目描述**：写清楚你做了什么、解决什么问题、面向谁使用。
4. **3‑5分钟演示视频Demo**：展示功能、实现原理、用到的技术、遇到的困难、学到的东西。
5. **README文档**：必须有部署/运行步骤，让评委拿到代码可以跑起来。

### 推荐加分（非强制，建议尽量做）
- 线上部署可访问版本
- 项目截图
- 技术栈清单
- PPT/补充文档

### AI工具规则
✅ **允许使用AI辅助**：头脑风暴、查bug、写辅助代码。
⚠️ 不能完全交给AI生成全部项目，需要你自己理解代码；**必须在项目描述写明哪些地方使用了AI辅助**。
❌ 抄袭、完全不能运行、半成品会直接取消资格。

### 可以做什么项目
没有规定题目，自由选题：Web网站、移动端App、桌面程序、游戏、硬件项目、AI工具都可以。
> 对你来说：可以把你正在做的小工具、知识库、硬件竞赛配套软件、学习工具拿来参赛。

## ⚖️评分标准（权重）
1. **Learning & Growth 学习成长 30%（权重最高！）**
重点看：你学到什么新东西、克服哪些困难、技术挑战、个人成长。新手项目哪怕简陋，只要体现出学习过程，这一项可以拿高分。
2. **Creativity & Impact 创意与价值 25%**
想法的原创性、解决真实问题、对用户的实际用处。
3. **Technical Execution 技术实现 25%**
项目能不能正常跑、代码质量、技术选型决策。不要求技术栈有多高深，决策合理即可。
4. **Presentation & Communication 展示表达 20%**
Demo视频质量、文档README、项目描述、能不能把自己的项目讲明白。

> 这个比赛核心导向：**不看项目多完美，看重学习与成长**，非常适合第一次参加海外hackathon。
