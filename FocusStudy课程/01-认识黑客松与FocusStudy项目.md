## 🧠 概念讲解

### 1. 黑客松是什么？

"Hackathon" = **Hack（黑客，指疯狂写代码）+ Marathon（马拉松）**。本质是：**在一个限定的时间段里，从零做出一个能运行的项目**。

你参加的是 **Beginner's Paradise — FirstCommit**，专门给新手办的：
- 主题：完全开放，做你想做的任何东西
- 截止：**2026-10-01 05:00**（注意是凌晨 5 点！建议最晚 9 月 28 日就全部提交完）
- 资格：13~21 岁学生，你可以参加
- 形式：单人 / 组队都行
- 奖金池：952 美元 + 各种会员和域名奖品

### 2. 必须提交的 5 样东西（一个都不能少）

| # | 提交物 | 简单说 |
|---|---|---|
| 1 | 可运行的项目 | 代码能跑起来，核心逻辑是比赛期间做的 |
| 2 | 公开 GitHub 仓库 | 代码放到 GitHub 上，全程有提交记录 |
| 3 | 项目描述 | 写清楚做了什么、解决什么问题、给谁用 |
| 4 | 3~5 分钟演示视频 | 展示功能 + 原理 + 困难 + 学到的东西 |
| 5 | README 文档 | 写清楚怎么运行，评委照着能跑起来 |

> 这套课程会帮你把这 5 样东西**逐件**做出来，别慌。

### 3. 评分标准（记住：学习成长最重要！）

| 评分项 | 权重 | 评委想看什么 |
|---|---|---|
| **Learning & Growth 学习成长** | **30%** | 你学到什么、克服什么困难、怎么成长的 |
| Creativity & Impact 创意价值 | 25% | 想法是否原创、有没有实际用处 |
| Technical Execution 技术实现 | 25% | 能不能跑、代码质量、技术选型是否合理 |
| Presentation 展示表达 | 20% | 视频、文档讲得清不清楚 |

**关键启示**：新手项目哪怕简陋，只要你能**讲清楚自己的学习过程**，第一项就能拿高分。这就是为什么这门课每节都让你写学习日志——那是给评委看的"成长证据"。

### 4. FocusStudy 是什么？

**FocusStudy = 学生专注学习管理系统**。它解决一个真实问题：**学生很难管住自己，学习没计划、不专注、不知道时间花哪了**。

它有三个核心功能模块：

```
┌─────────────────────────────────────────────┐
│                 FocusStudy                   │
├───────────────┬───────────────┬─────────────┤
│ ① 任务管理     │ ② 番茄专注计时器│ ③ 数据统计  │
│               │               │             │
│ 新增学习任务    │ 设定专注/休息时长│ 每日/每周    │
│ 科目/截止时间/  │ 开始/暂停/重置  │ 专注时长柱状图│
│ 优先级         │ 结束提醒       │ 科目占比饼图  │
│ 完成/删除      │ 自动记录专注数据│ 完成率       │
└───────────────┴───────────────┴─────────────┘
```

**技术栈**（每个词现在看不懂没关系，后面逐课学）：
- 前端（用户看到的界面）：**Vue3 + Vite + Element Plus + ECharts**
- 后端（处理数据的服务）：**Python + FastAPI**
- 存储（数据住哪）：**localStorage（浏览器本地）+ JSON 文件**（不搞复杂数据库，新手友好）

### 5. 前端 / 后端 / 存储 = 餐厅比喻 🍽️

- **前端** = 餐厅的**门面和大堂**：客人（用户）看到的一切，菜单、桌椅、服务员递来的菜。前端负责"好看 + 好操作"。
- **后端** = 餐厅的**后厨**：客人看不到，但菜（数据）在这里被加工、计算、统计。后端负责"算得对"。
- **存储** = 餐厅的**仓库/冰箱**：食材（数据）存放在这里，需要时取出来。

你要做的 FocusStudy：用户在前端点"开始专注"→ 前端把计时数据发给后端 → 后端算好统计数据 → 前端把统计图画给用户看。

## 🛠 动手做（今天的产出）

### 第一步：规划项目文件夹结构

打开你的项目文件夹 `E:\本科\Beginner's-Paradise‑FirstCommit`，在它里面新建两个空文件夹（现在建好，以后往里放代码）：

```
Beginner's-Paradise‑FirstCommit/
├── focusstudy-web/        # 以后放前端代码（Vue3）
└── focusstudy-server/     # 以后放后端代码（FastAPI）
```

### 第二步：写一份"项目日记"

在项目根目录新建 `项目日记.md`，写下（3~5 句就行）：

```markdown
# 项目日记
- 项目名：FocusStudy 学生专注学习系统
- 要解决的问题：学生不专注、没计划、不知道时间花哪了
- 目标用户：初高中生、大学生
- 我的三大功能：任务管理 / 番茄专注计时 / 数据统计
- 一句话简介（练练英文，后面要用）：
  A lightweight student focus study management system with
  pomodoro timer, task management and learning data visualization.
```

## ⚠️ 常见坑

- **坑 1**：觉得"我必须做出很牛的东西才能参赛"。错！新手赛看重成长，Demo 原型就可以。
- **坑 2**：想一次性把所有技术学完再动手。错！**边做边学**才是本课程的方式。
- **坑 3**：忽视截止时间是凌晨 5 点。建议你把自己的"个人截止日"设为 **9 月 28 日**。
