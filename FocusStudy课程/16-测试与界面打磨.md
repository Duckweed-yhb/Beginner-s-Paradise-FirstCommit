# 第 16 课：测试与界面打磨

> 目标：把项目从"能用"打磨到"好看、好用、稳定"——这是 Technical Execution（25%）和 Best Design（120$ 奖）的得分点。
> 耗时：约 2 天

---

## 📌 这节课你会学到

1. 系统化测试：功能自测清单（逐项打勾）
2. 边界情况处理：空数据、非法输入、时间跨天
3. 体验优化：空状态、加载状态、离开页面提醒、浏览器标题
4. UI 统一：配色、间距、响应式
5. 代码整理：组件拆分、命名规范、删除无用代码

## 🧠 概念讲解

### 1. 测试思维：别"感觉能用"，要"逐项验证"

专业做法是把功能列成清单，一项项测，每项标记 ✅/❌：

```
【任务模块】
□ 添加任务（正常输入）
□ 添加任务（空名称 → 有提示）
□ 添加任务（超长名称 100 字）
□ 切换完成状态
□ 编辑任务（改名称/科目/优先级/日期）
□ 删除任务
□ 刷新页面数据保留
□ 任务数为 0 时显示空状态

【计时器模块】
□ 开始倒计时
□ 暂停/继续
□ 重置
□ 切换专注/休息模式
□ 计时结束弹通知
□ 结束自动记录专注数据
□ 今日汇总数字正确

【统计模块】
□ 柱状图显示最近 7 天
□ 饼图显示科目占比
□ 汇总卡片数字正确
□ 无数据时空状态
□ 窗口缩放图表自适应
```

**发现 bug 的流程**：复现（怎么操作出来的）→ 看 F12 Console 报错 → 定位代码 → 修复 → 重测该项。

### 2. 常见边界情况

| 情况 | 期望行为 | 处理方式 |
|---|---|---|
| 空任务名称 | 不添加，提示 | `if (!name.trim()) return alert(...)` |
| 无专注记录 | 显示空状态 | `<el-empty>` |
| 后端没启动 | 前端还能用 | 容错退回 localStorage（第 15 课已做） |
| 跨天（23:59 开始专注） | 记录归属正确 | 用结束时刻的日期 |
| 快速连点按钮 | 不产生重复数据 | 添加时禁用按钮 / 状态判断 |

### 3. 体验细节（低成本高回报）

- **浏览器标签页标题**：`index.html` 里 `<title>FocusStudy - 专注学习</title>`
- **离开页面提醒**：计时器运行时切走页面弹提示（防沉迷切走）
- **未完成提醒**：列表顶部显示"X 项未完成"（第 10 课已做）
- **空状态文案**：温暖一点，"还没有任务，先添加一个吧"
- **favicon**：网站小图标（可在线生成一个番茄 emoji 图标）

## 🛠 动手做

### 第一步：运行功能自测清单

按上面的清单逐项测试（两个终端都启动）。**把结果记下来**，测出几个 bug 就修几个。这是比赛"学习成长"的真实素材：你经历了真实的 Debug 过程！

### 第二步：加"离开页面提醒"（体验亮点）

在 `src/views/TimerView.vue` 里加：

```javascript
import { watch } from "vue";

// 计时器运行时，离开页面给提示
watch(status, (val) => {
  if (val === "running") {
    window.addEventListener("beforeunload", beforeUnloadHandler);
  } else {
    window.removeEventListener("beforeunload", beforeUnloadHandler);
  }
});

function beforeUnloadHandler(e) {
  e.preventDefault();
  e.returnValue = "";   // 浏览器会弹"确定要离开吗"
}

// 组件卸载时移除监听
onUnmounted(() => {
  clearInterval(timerId);
  window.removeEventListener("beforeunload", beforeUnloadHandler);
});
```

### 第三步：给已完成任务加"删除线"样式（完成态更明显）

在 `TasksView.vue` 的表格列里，任务名称列改成：

```vue
<el-table-column label="任务名称" min-width="180">
  <template #default="{ row }">
    <span :style="{ textDecoration: row.done ? 'line-through' : 'none', color: row.done ? '#bbb' : '#333' }">
      {{ row.name }}
    </span>
  </template>
</el-table-column>
```

### 第四步：统一视觉（30 分钟搞定）

1. **主题色统一**：把散落的 `#ff6b35` 收敛——Element Plus 支持主题定制，简单做法是在 `src/` 下建一个全局样式文件 `src/styles.css`：

```css
/* 全局微调 */
:root {
  --el-color-primary: #ff6b35;   /* 让 Element Plus 所有主色变番茄橙 */
}
```

在 `main.js` 里 `import "./styles.css";`

2. **页面间距统一**：`App.vue` 的 `el-main` 加 `padding: 24px;`
3. **卡片圆角统一**：给全局加 `--el-border-radius-base: 10px;`

### 第五步：删除无用代码 + 提交

1. 检查 `App.vue` 里第 9 课的占位内容是否已全部替换
2. 删掉 `components/HelloWorld.vue`（Vite 模板自带的）
3. 检查有没有 `console.log` 调试残留（演示时别弹出来）
4. 提交：

```powershell
git add .
git commit -m "style: 界面打磨与体验优化（离开提醒/完成态/主题色）"
git push
```

## ⚠️ 常见坑

- **坑 1**：改全局变量不生效 → 确认 `styles.css` 在 `main.js` 里被 import 了，且放在 Element Plus CSS 之后。
- **坑 2**：beforeunload 提醒不弹 → 有些浏览器要求用户与页面有交互后该事件才生效，正常现象。
- **坑 3**：改完样式没变化 → 热更新偶发失灵，重启 `npm run dev`。
- **坑 4**：修复一个 bug 引入新 bug → 修完一项，重测该项 + 相邻功能（回归测试）。
