## 🧠 概念讲解

### 1. 番茄工作法

**番茄工作法**：专注 25 分钟（一个"番茄"）→ 休息 5 分钟 → 循环。4 个番茄后休息 15-30 分钟。这是 FocusStudy 计时器的理论来源，也是你 Demo 视频里要讲的故事。

### 2. setInterval：定时器

```javascript
// 每 1000 毫秒（1 秒）执行一次
const timerId = setInterval(() => {
  remaining.value--;
}, 1000);

// 停止定时器（关键！不然它永远在跑）
clearInterval(timerId);
```

**两个大坑**：
1. **定时器要清理**：组件销毁或暂停时必须 `clearInterval`，否则后台一直跑，还会叠加多个定时器。
2. **不要依赖 setInterval 计数**：用"目标结束时间 - 当前时间"算剩余秒数，比每秒减 1 更准确（浏览器切后台时 setInterval 会变慢）。

```javascript
// 推荐做法：记录"应该结束的时刻"
const endTime = Date.now() + 25 * 60 * 1000;
// 每秒：remaining = Math.ceil((endTime - Date.now()) / 1000)
```

### 3. 状态机：计时器的"生命周期"

```
       开始               暂停
空闲 ──────► 运行中 ──────────► 暂停中
 ▲            │  ▲               │
 │            │  └── 继续 ────────┘
 └──── 结束/重置 ◄── 倒计时到 0
```

用代码表达：一个 `status` 变量，取值为 `"idle" | "running" | "paused"`，不同状态按钮显示不同、行为不同。

### 4. 专注记录数据结构（重点设计）

每次完成一个番茄，记录一条数据——**第 12 课图表全靠它**：

```javascript
{
  id: 1720000000000,        // 唯一标识
  taskName: "完成数学第五章习题",  // 绑定哪个任务（可选）
  subject: "数学",           // 科目（图表按科目统计）
  minutes: 25,              // 专注分钟数
  date: "2026-09-10"        // 日期 YYYY-MM-DD（图表按日期统计）
}
```

## 🛠 动手做

把 `src/views/TimerView.vue` **完整替换**为：

```vue
<template>
  <div class="timer-page">
    <el-card class="timer-card">
      <h2>🍅 番茄专注计时器</h2>

      <!-- 模式切换：专注 / 休息 -->
      <el-radio-group v-model="mode" @change="resetTimer">
        <el-radio-button label="focus">专注 {{ focusMinutes }} 分钟</el-radio-button>
        <el-radio-button label="break">休息 {{ breakMinutes }} 分钟</el-radio-button>
      </el-radio-group>

      <!-- 环形进度条 + 倒计时 -->
      <div class="timer-body">
        <el-progress
          type="circle"
          :percentage="progressPercent"
          :width="220"
          :stroke-width="10"
          color="#ff6b35"
        >
          <template #default>
            <div class="time-text">{{ displayTime }}</div>
            <div class="mode-text">{{ mode === "focus" ? "专注中" : "休息中" }}</div>
          </template>
        </el-progress>
      </div>

      <!-- 绑定的任务（可选） -->
      <div class="task-bind">
        <el-select v-model="bindTaskId" placeholder="绑定当前任务（可选）" clearable style="width: 260px">
          <el-option v-for="t in unfinishedTasks" :key="t.id" :label="t.name" :value="t.id" />
        </el-select>
      </div>

      <!-- 控制按钮 -->
      <div class="btn-group">
        <el-button v-if="status === 'idle' || status === 'paused'" type="primary" size="large" @click="startTimer">
          ▶ 开始
        </el-button>
        <el-button v-else type="warning" size="large" @click="pauseTimer">⏸ 暂停</el-button>

        <el-button size="large" :disabled="status === 'idle'" @click="resetTimer">↺ 重置</el-button>
      </div>

      <!-- 今日专注汇总 -->
      <el-divider />
      <p class="today-summary">今日已专注：<b>{{ todayMinutes }}</b> 分钟（{{ todayCount }} 个番茄）</p>
    </el-card>
  </div>
</template>

<script setup>
import { ref, computed, watch, onUnmounted } from "vue";
import { ElNotification } from "element-plus";

// ===== 配置 =====
const focusMinutes = 25;   // 专注时长（可改成自定义，第 16 课优化）
const breakMinutes = 5;    // 休息时长

// ===== 计时器状态 =====
const mode = ref("focus");           // focus 专注 / break 休息
const status = ref("idle");          // idle 空闲 / running 运行 / paused 暂停
const totalSeconds = ref(focusMinutes * 60);   // 当前模式总秒数
const remaining = ref(totalSeconds.value);     // 剩余秒数
let timerId = null;                  // 定时器句柄

// 绑定的任务
const bindTaskId = ref(null);

// ===== 任务数据（与第 10 课共用同一个 localStorage key） =====
const unfinishedTasks = computed(() => {
  const tasks = JSON.parse(localStorage.getItem("focus_tasks")) || [];
  return tasks.filter(t => !t.done);
});

// ===== 专注记录 =====
const records = ref(JSON.parse(localStorage.getItem("focus_records")) || []);

function saveRecords() {
  localStorage.setItem("focus_records", JSON.stringify(records.value));
}

// ===== 显示 =====
const displayTime = computed(() => {
  const m = String(Math.floor(remaining.value / 60)).padStart(2, "0");
  const s = String(remaining.value % 60).padStart(2, "0");
  return `${m}:${s}`;
});

const progressPercent = computed(() => {
  return Math.round(((totalSeconds.value - remaining.value) / totalSeconds.value) * 100);
});

// ===== 核心逻辑 =====
function startTimer() {
  if (status.value === "idle") {
    totalSeconds.value = mode.value === "focus" ? focusMinutes * 60 : breakMinutes * 60;
    remaining.value = totalSeconds.value;
  }
  status.value = "running";

  // 每秒更新剩余时间
  timerId = setInterval(() => {
    remaining.value--;
    if (remaining.value <= 0) {
      clearInterval(timerId);
      timerId = null;
      onTimerComplete();
    }
  }, 1000);
}

function pauseTimer() {
  clearInterval(timerId);
  timerId = null;
  status.value = "paused";
}

function resetTimer() {
  clearInterval(timerId);
  timerId = null;
  status.value = "idle";
  totalSeconds.value = mode.value === "focus" ? focusMinutes * 60 : breakMinutes * 60;
  remaining.value = totalSeconds.value;
}

function onTimerComplete() {
  status.value = "idle";

  if (mode.value === "focus") {
    // 专注完成：记录数据（第 12 课图表的原料！）
    const bindTask = unfinishedTasks.value.find(t => t.id === bindTaskId.value);
    records.value.push({
      id: Date.now(),
      taskName: bindTask ? bindTask.name : "未绑定任务",
      subject: bindTask ? bindTask.subject : "未分类",
      minutes: focusMinutes,
      date: new Date().toISOString().slice(0, 10),   // 今天的日期 YYYY-MM-DD
    });
    saveRecords();

    ElNotification({
      title: "🎉 专注完成！",
      message: "太棒了，休息 5 分钟吧",
      type: "success",
      duration: 5000,
    });
    mode.value = "break";
  } else {
    ElNotification({
      title: "☕ 休息结束",
      message: "开始下一个番茄吧！",
      type: "info",
      duration: 5000,
    });
    mode.value = "focus";
  }
  resetTimer();
}

// 切模式时重置（@change 触发）
// 已在模板里绑定 resetTimer

// ===== 今日汇总 =====
const today = new Date().toISOString().slice(0, 10);
const todayMinutes = computed(() => {
  return records.value
    .filter(r => r.date === today)
    .reduce((sum, r) => sum + r.minutes, 0);
});
const todayCount = computed(() => records.value.filter(r => r.date === today).length);

// ===== 组件销毁时清理定时器（重要！防内存泄漏） =====
onUnmounted(() => {
  clearInterval(timerId);
});
</script>

<style scoped>
.timer-page { max-width: 640px; margin: 0 auto; }
.timer-card { text-align: center; padding: 24px; }
.timer-body { margin: 24px 0; display: flex; justify-content: center; }
.time-text { font-size: 44px; font-weight: bold; color: #333; letter-spacing: 2px; }
.mode-text { color: #888; margin-top: 4px; }
.task-bind { margin-bottom: 20px; }
.btn-group { display: flex; justify-content: center; gap: 12px; margin-top: 8px; }
.today-summary { color: #666; }
</style>
```

## ⚠️ 常见坑

- **坑 1**：连续点"开始" → 多个定时器叠加，倒计时加速。解决：开始前先 `clearInterval(timerId)`（本课用状态判断兜底）。
- **坑 2**：定时器在组件销毁后还在跑 → 报错/泄漏。`onUnmounted` 里必须清理。
- **坑 3**：`padStart(2, "0")` 不熟 → 它的作用是"如果不足 2 位，前面补 0"：`String(5).padStart(2,"0")` → `"05"`。
- **坑 4**：休息计时完成后切回专注 → 逻辑是 `resetTimer()` 在 `onTimerComplete` 里先被调用，注意别让模式被重置覆盖（本课代码顺序已处理）。
