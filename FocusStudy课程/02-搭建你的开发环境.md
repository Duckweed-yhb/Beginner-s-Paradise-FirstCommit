## 🧠 概念讲解

### 1. 你的工具清单（开发者的"四件套"）

| 工具 | 版本（我检测到的） | 它是干嘛的 | 对应课程用处 |
|---|---|---|---|
| **VSCode** | 装在 E:\VScode | 写代码的编辑器，相当于"作家的 Word" | 所有代码都在这里写 |
| **Node.js** | v22.23.2 | 让 JavaScript 脱离浏览器也能运行的环境 | 前端项目靠它启动（Vite） |
| **Python** | 3.14.7 | 一门很受欢迎的语言 | 写 FastAPI 后端 |
| **Git** | 2.51.1 | 代码版本管理工具 | 提交记录 = 参赛证据 |

> **类比**：VSCode 是你的"工作台"，Node 和 Python 是两种"语言环境"，Git 是你的"时光机"（随时能回到任意版本）。

### 2. 终端（命令行）是什么

**终端**是"用文字命令操作电脑"的窗口。VSCode 里按 **`` Ctrl + ` ``**（键盘左上角的反引号键 + Ctrl）就能打开内置终端。

PowerShell 最常用的几个命令（**你以后天天用**）：

| 命令 | 作用 | 示例 |
|---|---|---|
| `pwd` | 显示当前在哪个文件夹 | `pwd` |
| `ls` | 列出当前文件夹内容 | `ls` |
| `cd 路径` | 进入某个文件夹 | `cd E:\本科\Beginner's-Paradise‑FirstCommit` |
| `mkdir 名字` | 新建文件夹 | `mkdir test` |
| `clear` | 清空屏幕 | `clear` |

> 技巧：路径可以**拖拽文件夹到终端窗口**自动填入；按 **Tab 键**可以自动补全命令/路径。

## 🛠 动手做

### 第一步：验证四个工具（逐个复制到终端回车）

```powershell
node --version
npm --version
python --version
git --version
```

**预期输出**（版本号可能略有不同，只要有数字就说明安装成功）：
```
v22.23.2
10.9.8
Python 3.14.7
git version 2.51.1.windows.1
```

> 💡 如果哪个命令提示"不是内部或外部命令"，说明它没被加入 PATH，先告诉我，我帮你配。

### 第二步：在 VSCode 里安装插件

1. 打开 VSCode（开始菜单搜 VSCode，或终端输入 `code`）
2. 按 `Ctrl + Shift + X` 打开扩展商店
3. 搜索并安装以下插件（装完 VSCode 会提示重启，重启即可）：

| 插件名 | 作用 |
|---|---|
| **Chinese (Simplified) Language Pack** | 界面变中文 |
| **Vue - Official** | 写 Vue 代码的语法提示（第 8 课起有用） |
| **Python** | 写 Python 的语法提示（第 13 课起有用） |
| **ESLint** | 自动检查 JS 代码错误 |
| **Live Server** | 一键在浏览器预览网页（第 4、5 课用） |

### 第三步：跑通你的第一个程序

**Node 版（JavaScript）**：
1. 在 VSCode 里：文件 → 打开文件夹 → 选择 `E:\本科\Beginner's-Paradise‑FirstCommit`
2. 新建文件 `hello.js`，输入：

```javascript
// hello.js —— 你的第一个 JavaScript 程序
console.log("Hello, FocusStudy!");
console.log("我叫" + "你的名字");   // 把引号里的内容改成你的名字
```

3. 在终端运行：

```powershell
node hello.js
```

**看到 `Hello, FocusStudy!` 就成功了！** 🎉

**Python 版**：
1. 新建文件 `hello.py`，输入：

```python
# hello.py —— 你的第一个 Python 程序
print("Hello, FocusStudy!")
print("我是用 Python 写的")
```

2. 在终端运行：

```powershell
python hello.py
```

## ⚠️ 常见坑

- **坑 1**：终端里中文路径报错 → 用英文/拼音路径，或给路径加双引号：`cd "E:\本科\Beginner's-Paradise‑FirstCommit"`
- **坑 2**：命令敲了没反应 → 检查是否切换到了英文输入法（中文引号/括号会导致报错）
- **坑 3**：`node` 报错找不到文件 → 先 `cd` 到 hello.js 所在的文件夹再运行
- **坑 4**：VSCode 终端和系统终端搞混 → 都行，但建议统一用 VSCode 内置终端
