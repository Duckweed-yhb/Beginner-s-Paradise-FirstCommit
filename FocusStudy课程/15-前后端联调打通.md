## 🧠 概念讲解

### 1. 跨域（CORS）——新手必踩的坑

**问题**：前端跑在 `http://localhost:5173`，后端跑在 `http://localhost:8000`，**端口不同 = 不同"源"**。浏览器安全策略规定：不同源的网页**默认不能**互相请求数据。

```
浏览器 ──fetch http://localhost:8000/api/tasks──►  ❌ 被浏览器拦截
         （页面源是 5173，请求目标是 8000，跨域了）
```

**两种解决方式**（都教，联调用第一种）：

**方式 A：后端开 CORS（第 14 课已加！）**
后端告诉浏览器"我允许 5173 来访问我"：
```python
app.add_middleware(CORSMiddleware, allow_origins=["http://localhost:5173"], ...)
```

**方式 B：前端代理（Vite proxy）**
让前端把请求发给"自己"（5173），由 Vite 开发服务器转发给后端（8000）。浏览器视角里请求是同源的，不跨域。**推荐**，因为上线部署时也用同样思路。

### 2. Vite 代理配置

`vite.config.js` 里加 proxy：

```javascript
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";

export default defineConfig({
  plugins: [vue()],
  server: {
    proxy: {
      // 所有 /api 开头的请求，转发到后端 8000 端口
      "/api": {
        target: "http://127.0.0.1:8000",
        changeOrigin: true,
      },
    },
  },
});
```

配置后，前端代码里请求 `/api/tasks`（不写完整域名），Vite 自动转发到 `http://127.0.0.1:8000/api/tasks`。

### 3. fetch：发请求

```javascript
// GET：取数据
const res = await fetch("/api/tasks");
const tasks = await res.json();

// POST：提交数据
const res = await fetch("/api/tasks", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "写作业", subject: "数学" }),
});
const newTask = await res.json();
```

> `await` 表示"等这个操作完成"（网络请求是异步的）。用了 `await` 的函数要标记 `async`。

### 第二步：创建 API 封装层

新建 `focusstudy-web/src/api.js`：

```javascript
// 统一的请求封装：所有后端调用都走这里
async function request(url, options = {}) {
  const res = await fetch(url, {
    headers: { "Content-Type": "application/json" },
    ...options,
  });
  if (!res.ok) {
    throw new Error(`请求失败: ${res.status}`);
  }
  return res.json();
}

// ===== 任务接口 =====
export const fetchTasks = () => request("/api/tasks");
export const createTask = (task) =>
  request("/api/tasks", { method: "POST", body: JSON.stringify(task) });

// ===== 专注记录接口 =====
export const fetchRecords = () => request("/api/records");
export const createRecord = (record) =>
  request("/api/records", { method: "POST", body: JSON.stringify(record) });

// ===== 统计接口 =====
export const fetchStats = () => request("/api/stats");
```

> **为什么封装**：以后接口地址变了只改这一个文件；每个页面不用重复写 fetch 样板代码。这也是评委看代码质量时加分的地方。

### 第三步：任务页接入后端

修改 `src/views/TasksView.vue` 的 `<script setup>`：

```javascript
import { ref, reactive, computed, watch, onMounted } from "vue";
import { fetchTasks, createTask } from "../api";

const tasks = ref([]);

// 页面加载时从后端取数据
onMounted(async () => {
  try {
    tasks.value = await fetchTasks();
  } catch (e) {
    console.error(e);
    // 后端没启动时，退回 localStorage（容错设计，比赛演示不翻车）
    tasks.value = JSON.parse(localStorage.getItem("focus_tasks")) || [];
  }
});

// 添加任务：同时写后端和 localStorage
async function addTask() {
  const name = form.name.trim();
  if (!name) return alert("请填写任务名称");
  const newTask = await createTask({
    name,
    subject: form.subject,
    priority: form.priority,
    deadline: form.deadline || "未设置",
  });
  tasks.value.push(newTask);
  form.name = "";
}
```

> 保留 localStorage 作为**容错**：后端没启动时前端也能演示。这在比赛现场很有用（评委可能只跑前端）。

## ⚠️ 常见坑

- **坑 1**：请求 404 → 确认代理配置里 `"/api"` 前缀和请求路径一致；确认后端接口路径是 `/api/tasks`。
- **坑 2**：CORS 报错 → 先确认后端启动了、CORS 中间件配置了 5173；开发期也可以用 proxy 方式绕开。
- **坑 3**：POST 数据后端收不到 → 检查请求头 `Content-Type: application/json` 和 body 是否 JSON.stringify 过。
- **坑 4**：`await` 报语法错 → 所在函数必须声明为 `async`。
- **坑 5**：两个端口搞混 → 记住：前端 5173（浏览器打开这个），后端 8000（前端转发给它）。
