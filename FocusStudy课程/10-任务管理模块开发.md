## 🧠 概念讲解

### 1. 数据结构设计（写代码前先想清楚）

一个任务对象长这样：

```javascript
{
  id: 1720000000000,        // 唯一标识（用时间戳）
  subject: "数学",           // 科目
  name: "完成第五章习题",     // 任务名称
  deadline: "2026-09-20",   // 截止日期（字符串 YYYY-MM-DD）
  priority: "high",         // 优先级：high / medium / low
  done: false               // 是否完成
}
```

**设计原则**：字段只留必要的。多一个字段，后面就要多处理一个。

### 2. watch：自动保存数据

第 8 课我们是"每次操作后手动 save()"，Vue 提供了更省心的方式——**watch（侦听器）**：

```javascript
import { watch } from "vue";

// 只要 tasks 变了（增删改），自动执行保存
watch(tasks, () => {
  localStorage.setItem("focus_tasks", JSON.stringify(tasks.value));
}, { deep: true });
```

> `deep: true` 表示"深层侦听"——数组里某个对象的属性变了也能侦听到（比如切换 done）。

### 3. Element Plus 组件速览（本课用到）

| 组件 | 作用 | 本课用途 |
|---|---|---|
| `<el-card>` | 卡片容器 | 页面模块外壳 |
| `<el-form>` + `<el-form-item>` | 表单 | 新增任务表单 |
| `<el-input>` | 输入框 | 任务名称 |
| `<el-select>` + `<el-option>` | 下拉选择 | 选科目、优先级 |
| `<el-date-picker>` | 日期选择器 | 选截止日期 |
| `<el-table>` + `<el-table-column>` | 表格 | 任务列表展示 |
| `<el-tag>` | 标签 | 显示科目/优先级颜色 |
| `<el-button>` | 按钮 | 操作按钮 |
| `<el-empty>` | 空状态占位 | 列表为空时提示 |

## 🛠 动手做

把 `src/views/TasksView.vue` **完整替换**为下面的代码（亲手敲，逐段理解）：

```vue
<template>
  <div class="tasks-page">
    <!-- ===== ① 新增任务表单 ===== -->
    <el-card class="form-card">
      <h2>➕ 新增任务</h2>
      <el-form :inline="true" @submit.prevent>
        <el-form-item label="任务名称">
          <el-input v-model="form.name" placeholder="如：完成数学第五章习题" style="width: 240px" />
        </el-form-item>

        <el-form-item label="科目">
          <el-select v-model="form.subject" placeholder="选择科目" style="width: 130px">
            <el-option v-for="s in subjects" :key="s" :label="s" :value="s" />
          </el-select>
        </el-form-item>

        <el-form-item label="优先级">
          <el-select v-model="form.priority" style="width: 110px">
            <el-option label="高" value="high" />
            <el-option label="中" value="medium" />
            <el-option label="低" value="low" />
          </el-select>
        </el-form-item>

        <el-form-item label="截止日期">
          <el-date-picker
            v-model="form.deadline"
            type="date"
            value-format="YYYY-MM-DD"
            placeholder="选择日期"
            style="width: 160px"
          />
        </el-form-item>

        <el-form-item>
          <el-button type="primary" @click="addTask">添加任务</el-button>
        </el-form-item>
      </el-form>
    </el-card>

    <!-- ===== ② 任务列表 ===== -->
    <el-card>
      <h2>📋 我的任务（{{ unfinishedCount }} 项未完成）</h2>

      <el-empty v-if="tasks.length === 0" description="还没有任务，先添加一个吧" />

      <el-table v-else :data="tasks" stripe>
        <el-table-column label="完成" width="70" align="center">
          <template #default="{ row }">
            <el-checkbox :model-value="row.done" @change="toggleTask(row)" />
          </template>
        </el-table-column>

        <el-table-column prop="name" label="任务名称" min-width="180" />

        <el-table-column label="科目" width="100">
          <template #default="{ row }">
            <el-tag>{{ row.subject }}</el-tag>
          </template>
        </el-table-column>

        <el-table-column label="优先级" width="90">
          <template #default="{ row }">
            <el-tag :type="priorityType(row.priority)">
              {{ priorityText(row.priority) }}
            </el-tag>
          </template>
        </el-table-column>

        <el-table-column prop="deadline" label="截止日期" width="120" />

        <el-table-column label="操作" width="140">
          <template #default="{ row }">
            <el-button size="small" @click="editTask(row)">编辑</el-button>
            <el-button size="small" type="danger" @click="removeTask(row.id)">删除</el-button>
          </template>
        </el-table-column>
      </el-table>
    </el-card>

    <!-- ===== ③ 编辑对话框 ===== -->
    <el-dialog v-model="editDialogVisible" title="编辑任务" width="420px">
      <el-form label-width="80px">
        <el-form-item label="任务名称">
          <el-input v-model="editing.name" />
        </el-form-item>
        <el-form-item label="科目">
          <el-select v-model="editing.subject">
            <el-option v-for="s in subjects" :key="s" :label="s" :value="s" />
          </el-select>
        </el-form-item>
        <el-form-item label="优先级">
          <el-select v-model="editing.priority">
            <el-option label="高" value="high" />
            <el-option label="中" value="medium" />
            <el-option label="低" value="low" />
          </el-select>
        </el-form-item>
        <el-form-item label="截止日期">
          <el-date-picker v-model="editing.deadline" type="date" value-format="YYYY-MM-DD" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="editDialogVisible = false">取消</el-button>
        <el-button type="primary" @click="saveEdit">保存</el-button>
      </template>
    </el-dialog>
  </div>
</template>

<script setup>
import { ref, reactive, computed, watch } from "vue";

// ===== 数据 =====
const STORAGE_KEY = "focus_tasks";
const subjects = ["数学", "英语", "语文", "物理", "化学", "生物", "历史", "地理", "政治", "编程"];

// 表单初始值
const form = reactive({
  name: "",
  subject: "数学",
  priority: "medium",
  deadline: "",
});

// 任务列表：从 localStorage 读初始值
const tasks = ref(JSON.parse(localStorage.getItem(STORAGE_KEY)) || []);

// 编辑弹窗
const editDialogVisible = ref(false);
const editing = ref({});

// ===== 自动保存（核心！数据一变就存） =====
watch(tasks, () => {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks.value));
}, { deep: true });

// ===== 方法 =====
function addTask() {
  const name = form.name.trim();
  if (!name) {
    alert("请填写任务名称");
    return;
  }
  tasks.value.push({
    id: Date.now(),
    name,
    subject: form.subject,
    priority: form.priority,
    deadline: form.deadline || "未设置",
    done: false,
  });
  form.name = "";   // 清空输入
}

function toggleTask(row) {
  row.done = !row.done;   // 切换完成状态（watch 会自动保存）
}

function removeTask(id) {
  tasks.value = tasks.value.filter(t => t.id !== id);
}

function editTask(row) {
  editing.value = { ...row };      // 浅拷贝，避免直接改原数据
  editDialogVisible.value = true;
}

function saveEdit() {
  const target = tasks.value.find(t => t.id === editing.value.id);
  if (target) {
    target.name = editing.value.name;
    target.subject = editing.value.subject;
    target.priority = editing.value.priority;
    target.deadline = editing.value.deadline;
  }
  editDialogVisible.value = false;
}

// ===== 计算属性 =====
const unfinishedCount = computed(() => tasks.value.filter(t => !t.done).length);

// 优先级显示
function priorityText(p) {
  return { high: "高", medium: "中", low: "低" }[p] || "中";
}
function priorityType(p) {
  return { high: "danger", medium: "warning", low: "info" }[p] || "info";
}
</script>

<style scoped>
.tasks-page { max-width: 960px; margin: 0 auto; }
.form-card { margin-bottom: 20px; }
h2 { margin-top: 0; font-size: 18px; }
</style>
```

## ⚠️ 常见坑

- **坑 1**：`el-checkbox` 直接 `v-model="row.done"` 可以，但用 `:model-value` + `@change` 更可控（本课写法）。别两种混着用。
- **坑 2**：`el-date-picker` 不设 `value-format` 时返回的是 Date 对象，存 localStorage 会变字符串，所以一定要 `value-format="YYYY-MM-DD"`。
- **坑 3**：`JSON.parse(localStorage.getItem(...)) || []` 忘记兜底 → 第一次运行时 localStorage 为空，`JSON.parse(null)` 返回 null，`.filter` 会报错。
- **坑 4**：编辑时直接 `editing.value = row`（不拷贝）→ 弹窗里每改一个字，表格里就跟着变。用展开运算符拷贝。
