## 🧠 概念讲解

### 1. 为什么要用框架？

回忆第 7 课的代码：每次数据变化，你都要手动操作 DOM——`render()` 清空列表 → `createElement` → `appendChild`……代码一大半都在"指挥 DOM"。

**Vue 的核心思想：数据驱动视图。** 你只管改数据，Vue 自动帮你更新页面。

```
手动 DOM（第7课）：数据变了 → 你自己找到元素 → 自己改 → 自己渲染
Vue（第8课）：    数据变了 → Vue 自动更新页面 ✓
```

### 2. 响应式数据：ref / reactive

```javascript
import { ref, reactive } from "vue";

const count = ref(0);              // ref：包装一个值（数字/字符串/布尔）
count.value = 1;                   // 注意：读/写 ref 要 .value（模板里不用）

const user = reactive({ name: "小明", age: 17 });  // reactive：包装对象
user.name = "小红";                // 直接改属性即可
```

### 3. 模板语法与指令

Vue 的"页面部分"写在 `<template>` 里，HTML + 特殊指令：

```html
<!-- 插值：把数据显示出来 -->
<p>{{ count }}</p>

<!-- v-if / v-else：条件显示 -->
<p v-if="count > 0">有数据</p>
<p v-else>空</p>

<!-- v-for：循环渲染列表（:key 是唯一标识，必须写） -->
<li v-for="task in tasks" :key="task.id">{{ task.name }}</li>

<!-- @click：点击事件（@ 是 v-on 的简写） -->
<button @click="addTask">添加</button>

<!-- v-model：输入框和变量"双向绑定"，输入即改数据 -->
<input v-model="newTaskName">

<!-- :class / :style：动态绑定（: 是 v-bind 的简写） -->
<li :class="{ done: task.done }">
```

### 4. 计算属性 computed

想根据现有数据"算"出新数据（并缓存结果）：

```javascript
import { computed } from "vue";

const tasks = ref([]);
const unfinished = computed(() => {
  return tasks.value.filter(t => !t.done).length;   // 未完成任务数
});
```

> `computed` 就像"带记忆的自动计算器"：依赖的数据变了它才重算。

## 🛠 动手做：Vue 版迷你任务清单

本课用 **CDN 方式**快速体验 Vue（不用建项目，一个 html 搞定）。第 9 课再建正式项目。

在 `practice/html/` 下新建 `todo-vue.html`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue 版迷你任务清单</title>
  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
  <style>
    body { font-family: "Microsoft YaHei", sans-serif; max-width: 500px; margin: 40px auto; padding: 0 16px; }
    h1 { text-align: center; }
    .input-row { display: flex; gap: 8px; margin: 16px 0; }
    .input-row input { flex: 1; padding: 10px; border: 1px solid #ddd; border-radius: 8px; }
    .input-row button { padding: 10px 16px; background: #ff6b35; color: white; border: none; border-radius: 8px; cursor: pointer; }
    ul { list-style: none; padding: 0; }
    li {
      display: flex; justify-content: space-between; align-items: center;
      padding: 12px; border: 1px solid #eee; border-radius: 8px; margin-bottom: 8px; cursor: pointer;
    }
    li.done { opacity: 0.5; text-decoration: line-through; }
    .del { color: #e74c3c; cursor: pointer; border: none; background: none; font-size: 16px; }
  </style>
</head>
<body>
  <div id="app">
    <h1>📋 Vue 任务清单</h1>
    <p>未完成任务：{{ unfinishedCount }}</p>

    <!-- v-model 双向绑定 + @click 添加 -->
    <div class="input-row">
      <input v-model="newTaskName" placeholder="输入任务名称" @keydown.enter="addTask">
      <button @click="addTask">添加</button>
    </div>

    <!-- v-for 渲染列表；点击切换完成；✕ 删除 -->
    <ul>
      <li
        v-for="task in tasks"
        :key="task.id"
        :class="{ done: task.done }"
        @click="toggleTask(task)"
      >
        {{ task.name }}
        <button class="del" @click.stop="removeTask(task.id)">✕</button>
      </li>
    </ul>
  </div>

  <script>
    const { createApp, ref, computed } = Vue;

    createApp({
      setup() {
        // ===== 数据 =====
        const STORAGE_KEY = "vue_tasks";
        const newTaskName = ref("");
        const tasks = ref(JSON.parse(localStorage.getItem(STORAGE_KEY)) || []);

        // 每次数据变化都存一次（watch 第 9 课再正式介绍，这里简单粗暴每次操作都存）
        function save() {
          localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks.value));
        }

        // ===== 方法 =====
        function addTask() {
          const name = newTaskName.value.trim();
          if (!name) return;
          tasks.value.push({ id: Date.now(), name, done: false });
          newTaskName.value = "";
          save();
        }

        function toggleTask(task) {
          task.done = !task.done;
          save();
        }

        function removeTask(id) {
          tasks.value = tasks.value.filter(t => t.id !== id);
          save();
        }

        // ===== 计算属性 =====
        const unfinishedCount = computed(() => tasks.value.filter(t => !t.done).length);

        return { newTaskName, tasks, addTask, toggleTask, removeTask, unfinishedCount };
      }
    }).mount("#app");
  </script>
</body>
</html>
```

### 对比一下！

把第 7 课的 `todo.html` 和这节课的 `todo-vue.html` 并排看：
- 第 7 课：`render()` + `createElement` + `appendChild`……几十行手动 DOM 操作
- 第 8 课：`v-for` 一行渲染列表，`@click` 一行绑定事件，**没有一行手动 DOM 操作**

**这就是框架的价值。** 体会到了吗？

### 验证

1. 添加 / 切换完成 / 删除都正常
2. 未完成任务数实时更新（computed 生效）
3. 刷新后数据还在（localStorage 依然在）

## ⚠️ 常见坑

- **坑 1**：模板里写 `tasks.value` → 模板中自动解包，直接写 `tasks`，不要 `.value`。
- **坑 2**：`v-for` 忘写 `:key` → 控制台警告，且列表更新会有诡异 bug。`:key` 必须唯一。
- **坑 3**：`setup()` 里定义了变量但没 `return` → 模板里用不到。返回对象里有什么，模板才能用什么。
- **坑 4**：CDN 版和正式项目（第 9 课）写法略有差异，正式项目用 `import` 方式，本课体验为主。
